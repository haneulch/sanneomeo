# 산너머 (SanNeomeo)

> Beyond the famous peaks, into the heart of Korea.

외국인 등산 관광객에게 지역의 숨은 명산·사찰을 취향 기반으로 큐레이션하고, 등산-사찰-지역상권을 잇는 소비 동선과 방문 데이터를 지자체 관광 기획에 환류시켜 **지역 관광 자원을 지속가능한 발전 전략으로 전환**하는 웹 서비스입니다.

## 배경 (관광데이터 활용 공모전)

**해결 과제**: 지역 관광 잠재력을 지속가능한 지역의 발전 전략으로 전환하지 못하는 기획의 한계

- 외국인 등산 목적 방한 FIT(개별 여행객)가 급증하고 있지만, 방문지는 북한산·설악산 등 유명 산에 집중
- 지역에는 동급의 산·사찰 자원이 있으나 외국어 정보 부재, 상품화 미비, 데이터 기반 기획 부재
- 산너머는 **자원을 상품으로** (큐레이션 + 스토리텔링), **방문을 소비로** (하산 후 지역 동선 설계 + 패스포트), **소비를 전략으로** (방문 데이터의 지자체 환류) 전환하는 순환 구조를 제안

## 실행

Next.js(App Router) + React + TypeScript.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 프로덕션 빌드
```

모바일 뷰(414px) 기준으로 제작. 데스크톱 브라우저에서는 중앙 정렬된 폰 프레임으로 표시됩니다.
초기 단일 HTML 프로토타입은 `prototype/index.html`에 보존.

### 백엔드 — 공공데이터 연동

공공데이터포털 인증키 하나로 전 API 호출. 설정:

```bash
cp .env.example .env.local
# .env.local에 일반 인증키(Decoding) 입력: DATA_GO_KR_KEY=...
```

키가 없거나 호출 실패 시 각 라우트는 정적 데이터로 자동 폴백 (`source` 필드로 구분).

| 라우트 | 데이터 | 상태 |
|---|---|---|
| `GET /api/mountains` | 한국등산트레킹지원센터 100대명산 목록 → 큐레이션 18좌와 병합 | ✅ 라이브 |
| `GET /api/safety` | 기상청 초단기실황 (기온·강수 → 폭염/우천 판정) + 일몰 계산 | ✅ 라이브 |
| `GET /api/nearby` | TourAPI 영문 위치기반 주변 관광지 | ✅ 라이브 |
| `GET /api/temples` | 행안부 전통사찰 (CSV 정제본) | ✅ 정적 |
| `GET /api/seasonal` | 월별 계절 픽 + TourAPI 진행 중 축제 (산 30km 매칭) | ✅ 라이브 |
| `GET /api/transit` | TAGO 열차 시간표 (서울→허브역, 역 ID 런타임 해석) | ⏳ 승인 대기 |

## 주요 기능

### 1. 온보딩 취향 설문
- 언어 선택: **영어 / 한국어 / 일본어 / 중국어**
- 난이도(쉬움·보통·도전), 산행 시간(반나절·하루·1박 2일), 관심사(화강암 능선·템플스테이·단풍·바다 전망·온천) 입력 → 맞춤 추천 기반

### 2. 둘러보기 (Discover)
- 취향 기반 큐레이션: "설악산이 좋았다면 → 대둔산·선운산·모악산" 식의 유사 경험 매칭
- 산마다 취향 매칭률, 난이도, 소요 시간, 연계 사찰, 추천 이유 표시
- 100대 명산 스탬프 투어 진행 배너

### 3. 산 상세
- 난이도 국제 표준(YDS) 병기, 왕복 시간·거리
- **구글맵 연결** 버튼
- 대중교통 상세 안내 (KTX → 버스 환승, 요금, **막차 시간 경고**) — 렌터카 없는 외국인의 핵심 페인포인트 해소
- 하산 후 지역 소비 동선: 사찰 → 로컬 식당(제휴 할인) → 온천

### 4. 산 목록
- 산림청 100대 명산 기반 전체 목록 (프로토타입: 18개 수록)
- **필터**: 지역별(수도권·강원·충청·전라·경상·제주) × 난이도별(쉬움·보통·도전)
- **정렬**: 추천순 / 가까운순(Geolocation, 실패 시 서울 기준 폴백) / 높은 고도순
- 행별 구글맵 바로가기(📍), 스탬프 획득 여부 표시

### 5. 트레일 패스포트 (게이미피케이션)
- GPS 인증 스탬프 수집 — 100대 명산 진행률 (숨은 지역 명산은 2배 포인트 = 분산 인센티브)
- **챌린지 & 뱃지**: 첫 산행, 전북 5좌, 천년고찰 순례, 100대 명산 완등 — 완성 시 뱃지 지급
- **히든 뱃지**: 전국 비밀 명산 7곳, 목록·지도 비공개, 현장 스탬프 순간에만 공개 — 탐험 동기 부여
- 스탬프 연동 지역 가맹점 쿠폰 — 소비가 지역에 남는 구조

## 다국어 지원

우측 상단(또는 온보딩) 언어 전환: English / 한국어 / 日本語 / 中文.
산 이름은 언어별 표기 지원 (예: 대둔산 / Daedunsan / 大芚山).

| 데이터 | 출처 | 용도 |
|---|---|---|
| TourAPI 다국어 관광정보 | 한국관광공사 | 큐레이션·상세 정보 |

| 100대 명산·등산로 | 산림청 | 목록·난이도·스탬프 기준 |

## 기술 구성

- Next.js 15 (App Router) + React 19 + TypeScript
- 백엔드: Next.js API Routes (`app/api/*`) — 공공데이터 프록시·캐싱 계층
- 스타일: 순수 CSS 디자인 토큰, 다크 모드 지원 (`prefers-color-scheme`)
- i18n: 언어별 사전 객체 (`lib/i18n.ts`), 4개 언어
- 거리 계산: 하버사인 공식, 브라우저 Geolocation API
